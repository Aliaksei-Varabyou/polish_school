# Matema — тренажёр математики

Веб-тренажёр для подготовки к контрольным и самостоятельным по польской программе
(szkoła podstawowa 5–8, liceum 1–4, poziom podstawowy / rozszerzony).
Задачи генерирует ИИ (Google Gemini, бесплатный тариф). Интерфейс и задачи на RU / EN / PL.

## Структура

```
apps/api                Fastify API: /api/trainers/:id/{topics,generate,feedback}, /api/health
apps/web                портал: шапка, каталог, ленивая загрузка тренажёров (/t/:id)
packages/core           общие zod-схемы и типы (Task, Topic, TaskSlot…)
packages/ai             LLMClient: Gemini, mock, общая очередь запросов
packages/task-pool      пул проверенных задач (SQLite, с trainer_id)
packages/trainer-sdk    контракт тренажёра (TrainerServer / TrainerWeb) и общий пайплайн генерации
packages/ui             общие React-компоненты
packages/trainers/math  тренажёр математики:
                          src/         темы и проверка ответов (общее для web и api)
                          src/server/  промпты, валидация задач, mock-ответы, mathTrainer
                          src/web/     экраны, store, переводы, mathTrainerWeb
```

## Запуск

```bash
npm install
cp .env.example .env        # вписать GEMINI_API_KEY (https://aistudio.google.com/apikey)
npm run dev                 # сервер :8787 + фронт :5173 (прокси /api)
```

Без ключа работает `LLM_PROVIDER=mock`: простые арифметические задачи, всё остальное как с настоящим ИИ.

Продакшен: `npm run build && npm start`. Сервер сам отдаёт собранный фронт из `apps/web/dist`.

## Как генерируются задачи

1. Задачи распределяются по выбранным темам. Сложность: примерно 30% лёгких, 50% средних, 20% трудных.
   Часть задач (`POOL_REUSE_RATIO`, по умолчанию половина) берётся из пула уже проверенных задач, которые этот ученик ещё не видел.
   Остальные генерируются пачками до 5 задач: темы внутри пачки смешиваются, поэтому 10 задач — это 2 запроса к ИИ при любом числе тем.
   Все запросы к ИИ проходят через общую очередь сервера (`LLM_MAX_CONCURRENT`, `LLM_RPM`).
2. Gemini возвращает JSON по схеме. Для числовых ответов модель также присылает `verifyExpression`: выражение, которое вычисляет ответ из условия.
3. Сервер проверяет каждую задачу (`packages/trainers/math/src/server/verifyTask.ts`):
   - схема данных;
   - `verifyExpression` должен совпасть с ответом (через mathjs);
   - в задачах с выбором ровно один верный вариант.

   Отбракованные задачи догенерируются. Прошедшие проверку сохраняются в пул (SQLite).
   Если ИИ недоступен или квота исчерпана, недостающие задачи добираются из пула.
   Модели перебираются по порядку (`GEMINI_MODEL`, затем `GEMINI_FALLBACK_MODEL`). Модель, получившая 429, пропускается
   на время из ответа Google, а при исчерпании суточной квоты — на час. Состояние видно в `GET /api/health`.
4. Ответ ученика проверяется на клиенте (`packages/trainers/math/src/answer.ts`). Эквивалентными считаются `0,5`, `1/2` и `.5`; `2√3` и `2*sqrt(3)`. Корни проверяются без учёта порядка (`2; -3`), выражения — подстановкой значений.

## Переменные окружения

| Переменная | По умолчанию | |
|---|---|---|
| `LLM_PROVIDER` | `gemini`, если есть ключ, иначе `mock` | |
| `GEMINI_API_KEY` | — | ключ Google AI Studio |
| `GEMINI_MODEL` | `gemini-3.5-flash-lite` | модели и лимиты бесплатного тарифа меняются, сверяйтесь с AI Studio |
| `GEMINI_FALLBACK_MODEL` | `gemini-3.1-flash-lite,gemini-3.6-flash` | запасные модели через запятую; у каждой своя квота |
| `LLM_MAX_CONCURRENT` | `4` | сколько запросов к ИИ одновременно на весь сервер |
| `LLM_RPM` | `15` (mock: без лимита) | запросов к ИИ в минуту на весь сервер |
| `LLM_QUEUE_WAIT_MS` | `45000` | сколько запрос может ждать в очереди, потом ошибка «слишком много запросов» |
| `TASK_DB_PATH` | `apps/api/data/tasks.db` | файл пула задач |
| `POOL_REUSE_RATIO` | `0.5` | доля задач из пула в каждой тренировке |
| `PORT` | `8787` | |
| `CORS_ORIGIN` | любой | список через запятую |

## Справочник тем

`packages/trainers/math/src/curriculum/{sp,lo}.ts` — это черновая раскладка по классам на основе популярных учебников.
Сверьте её с podstawa programowa и учебником конкретной школы. Подтемы записаны по-польски, они идут в промпт.

## Как добавить тренажёр

1. Создать пакет `packages/trainers/<id>` (по образцу `math`) с тремя входами:
   - `.` — темы и проверка ответа (используются и в браузере, и на сервере);
   - `./server` — объект `TrainerServer`: `topicsFor`, `generateTaskBatch` (промпт + JSON-схема + mock-ответ), `verifyTask`, `checkAnswer`, `generateFeedback`;
   - `./web` — объект `TrainerWeb`: название, описание, иконка, переводы (namespace = id) и `load: () => import("./App.tsx")`.
2. Зарегистрировать тренажёр в `apps/api/src/trainers.ts` и `apps/web/src/trainers.ts`.
3. Пайплайн генерации (пул, пачки, очередь, догенерация) общий — в `@portal/trainer-sdk/server`, его писать не нужно.

Приложение тренажёра получает `lang` и `setLanguageLocked` от портала и грузится отдельным чанком.
